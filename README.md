## 📌 Overview
This project is a content-based recommendation system that suggests TV shows and movies similar to user favorites. It utilizes **TF-IDF (Term Frequency-Inverse Document Frequency)** vectorization and **Cosine Similarity** to analyze unstructured text data (plots, genres, casts) and rank content based on similarity scores.

## ✨ Key Features
* **NLP Analysis:** Processes and cleans unstructured text data using NLTK and Scikit-learn.
* **Similarity Engine:** Calculates similarity scores between thousands of titles using Cosine Similarity.
* **Interactive Interface:** Built with Streamlit for real-time recommendations.

## 🛠️ Tech Stack
* **Language:** Python
* **Libraries:** Pandas, NumPy, Scikit-learn, NLTK
* **Web Framework:** Streamlit
* **Dataset:** Netflix Movies and TV Shows (Kaggle)
